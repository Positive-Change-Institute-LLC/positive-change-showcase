# Contributing & Contact

This is a showcase repository for Positive Change Institute LLC. Start with the [README](./README.md) and [REPO_MAP.md](./REPO_MAP.md).

- **Questions, enterprise or partnership inquiries:** open a GitHub issue.
- **Bugs or doc fixes:** open an issue or a pull request with a short description of the change.
- **Code changes:** for the DeFi suite, run `pip install -r requirements.txt && pip install -e .` inside [`pci_defi_analysis_suite/`](./pci_defi_analysis_suite/).

All systems, engines and products are the property of Positive Change Institute LLC; see [IP_PORTFOLIO.md](./IP_PORTFOLIO.md).
