# 🜂 CORE MODULES

## 1. AMM Analysis Engine
**Purpose:** Analyze Automated Market Maker mechanics and risks

**Analyzes:**
- Curve types (x*y=k, stable swap, concentrated liquidity)
- Invariant stability
- Slippage and price impact
- Liquidity depth
- Fee structures
- Volatility exposure

**Output:**
```json
{
  "curve": "xyk",
  "invariant": 1234567890,
  "fee": 0.003,
  "invariant_stability": "high",
  "price_impact_small": 0.0001,
  "price_impact_large": 0.0523,
  "volatility_exposure": "medium",
  "liquidity_depth": "high",
  "oracle_risk": "medium"
}
```

---

## 2. LP Risk Assessment
**Purpose:** Evaluate liquidity provider impermanent loss and returns

**Analyzes:**
- Impermanent loss exposure
- Fee APR vs. IL break-even
- Volatility impact
- Capital efficiency
- Rebalancing costs

**Output:**
```json
{
  "impermanent_loss_estimate": 0.0234,
  "fee_apr": 0.1047,
  "synthetic_yield": 0.0523,
  "volatility_exposure": "high",
  "il_breakeven_days": 28
}
```

---

## 3. Yield Analysis Engine
**Purpose:** Decompose yield into real, emissions, and synthetic components

**Analyzes:**
- Real yield (from protocol fees)
- Emissions yield (governance token rewards)
- Synthetic yield (farming incentives)
- Yield sustainability
- Dilution trajectory

**Output:**
```json
{
  "real_yield": 0.0521,
  "emissions": 0.0234,
  "synthetic_yield": 0.0103,
  "yield_quality": "high",
  "sustainability_score": 87
}
```

---

- Liquidation risk

# 🜃 API ENDPOINTS

## REST API (FastAPI)

### GET /analysis
Returns complete structural analysis for specified protocol
```
GET /analysis?protocol=aave&chain=ethereum
{
  "amm": { ... },
  "lp": { ... },
  "yield": { ... },
  "lending": { ... },
  "bridge": { ... },
  "routing": { ... },
  "scenarios": { ... },
  "resilience_score": 87
}
```

### GET /amm/{pool_id}
Analyze specific AMM pool
```
GET /amm/0x1234...
{ "curve": "xyk", "invariant": 123456, ... }
```

### GET /lp/{position_id}
Analyze specific LP position
```
GET /lp/0x5678...
{ "impermanent_loss": 0.0234, "fee_apr": 0.10, ... }
```

### GET /yield/{protocol}
Analyze yield breakdown
```
GET /yield/curve
{ "real_yield": 0.052, "emissions": 0.023, ... }
```

### GET /lending/{market}
Analyze lending market
```
GET /lending/ethereum_dai
{ "utilization": 0.64, "liquidation_risk": "medium", ... }
```

### GET /scenarios/{protocol}
Run stress tests
```
GET /scenarios/uniswap
{ "volatility_shock": {...}, "liquidity_withdrawal": {...}, ... }
```

### GET /resilience/{protocol}
Get resilience score
```
GET /resilience/aave
{ "score": 87, "grade": "A", "recommendation": "..." }
```
